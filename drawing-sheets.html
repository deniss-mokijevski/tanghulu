🖍️ Drawing sheets

Print these pages. Each square is one drawing for the game — the picture and word above it show what to draw. Afterwards, take a photo or scan of each drawing, crop it roughly to the square, and save it in the game folder with the file name printed under the word (for example assets/foods/strawberry.png). White paper around the drawing is removed automatically when the game runs from a web server (see README.md).
