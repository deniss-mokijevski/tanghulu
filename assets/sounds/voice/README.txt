Spoken sentences (optional). The file name is the sentence's name in config.js "phrases":
  call.mp3, welcome.mp3, tapFood.mp3, ..., yay.mp3 (the cheer)
and one greeting per place:
  place-kitchen.mp3, place-beach.mp3, place-space.mp3

.mp3, .m4a or .wav. Without a file the game uses its built-in Estonian voice.
